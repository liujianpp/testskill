# 测试点模板

测试点模板与字段说明，供在 specs/ 下生成测试点文件时参考。用等价类、边界值、场景法、错误推测等设计方法推导「要测什么」，并为每条测试点标注所用方法。测试点 = 覆盖要点/验收方向，不写完整步骤、预期结果。

---

## 测试点（如 testpoints.md / feature_<name>.md）

**用途**：列出「要测什么」的要点清单，供 spectest-generate 在 design.md 中做覆盖矩阵与用例提纲后再展开为完整测试用例。

```markdown
# 测试点：<标题>

## 概述
- 本变更要验证的范围（一两段话；若有 test-plan.md，与其范围对齐）

## 测试点列表

| 模块 | 测试点 | 设计方法 | 验收方向 |
|------|--------|----------|----------|
| （按功能拆，如登录页） | （要测什么） | 等价类 / 边界值 / 场景法 / 错误推测 | （一句话，不写步骤） |
```

## 结构化格式（自动生成模式，含数据库验证时）

自动生成模式按功能/API 分文件（`feature_<name>.md` / `api_<name>.md`），每条测试点包含：
测试点编号、标题、**设计方法**、用户故事、验收条件、测试数据、验证SQL、优先级、测试类型。字段说明与示例见 [SKILL.md](../SKILL.md) 手动编写模式的测试点模板。
