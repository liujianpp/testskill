# SpecTest 参考文档

本目录包含 SpecTest 技能使用的核心参考文档。

## 文档说明

### design-methods.md
测试用例设计方法指南，分为两部分：

**第一部分：功能测试用例设计方法**
- 场景法（功能测试首选）
- 等价类划分
- 边界值分析
- 判定表法
- 结对思维/Pairwise
- 错误猜测
- 功能测试步骤编写规范
- 测试维度覆盖检查清单
- 覆盖率检查公式
- 用例数量控制

**第二部分：API测试用例设计方法**
- 等价类划分（API版本）
- 边界值分析（API版本）
- 结对思维/Pairwise Testing（API版本）
- 场景法（API版本）
- 错误猜测（API版本）
- 数据库约束驱动的用例生成
- 安全测试用例设计

### testcase-headers.md
标准测试用例表头定义（25 列格式），包含：
- 详细的字段说明
- 用例版本规则
- 测试项说明
- 覆盖类型说明（正向/负向/边界/安全/权限）
- 用例优先级标准
- 验证 SQL 规范
- Excel 样式规范

## 使用方式

这些文档供 AI 在设计测试用例时参考，确保：
1. 测试用例设计符合规范
2. 覆盖率目标达成（正向≥40%、负向≥30%、边界≥20%、安全≥10%）
3. 所有字段填写正确
