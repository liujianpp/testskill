# 标准测试用例表头定义

本文件定义测试用例 Excel 输出的标准列结构，与功能测试用例保持完全一致（共 25 列）。

## 标准列定义

| 列号 | 列名 | 英文Key | 必填 | 取值说明 |
|------|------|---------|------|---------|
| A | 系统/项目 | project | 可选 | 所属系统或项目名称，可为空 |
| B | 模块 | module | ✅ | API 所属业务模块，如"地址管理" |
| C | 功能 | feature | ✅ | 具体功能点，如"地址搜索" |
| D | 测试项 | test_item | ✅ | 本条用例的测试维度/场景描述，如"有效关键字模糊搜索" |
| E | 用例标题 | title | ✅ | 简明动词短语，如"有效关键字标准搜索返回匹配结果" |
| F | 前置条件 | preconditions | ✅ | 执行用例前须满足的条件（环境、数据、权限等） |
| G | 涉及到数据库表 | db_tables | 可选 | 如 lsp_dev.lsp_address_suburb |
| H | 测试数据 | test_data | ✅ | 入参 JSON（完整 Request Body 或 Query Params） |
| I | 测试步骤 | steps | ✅ | 按序编号，每步可操作，包含具体请求内容 |
| J | 预期结果 | expected_result | ✅ | 明确到：HTTP 状态码 + 响应字段 + 业务含义 |
| K | 验证SQL | validation_sql | ✅ | SELECT 语句，验证数据库实际变更，可直接执行 |
| L | 实际结果 | actual_result | — | 执行阶段填写，设计时留空 |
| M | 是否通过 | is_passed | — | 执行阶段填写，设计时留空 |
| N | 预计工时(h) | estimated_hours | 可选 | 预计执行工时，如 0.5 |
| O | 执行时间(年月日) | execute_date | — | 执行阶段填写，设计时留空 |
| P | 测试进度(%) | test_progress | — | 执行阶段填写，设计时留空 |
| Q | 用例类型 | case_type | ✅ | 固定值：API测试 |
| R | 用例优先级 | priority | ✅ | 枚举：P0 / P1 / P2 / P3 |
| S | 是否回归用例 | is_regression | ✅ | 是 / 否 |
| T | 是否阻塞上线 | is_blocker | ✅ | 是 / 否 |
| U | 关联需求ID | requirement_id | 可选 | 需求文档 ID（如有） |
| V | API URL | api_url | ✅ | 格式：{METHOD} {path}，如 POST /address/search |
| W | BUG数 | bug_count | — | 默认 0，执行后更新 |
| X | BUG未解决数 | bug_unresolved | — | 默认 0，执行后更新 |
| Y | 用例版本 | case_version | ✅ | 从 1 开始，同功能点旧用例最大版本+1 |

> **注意**：`test_type`（正向/负向/边界/安全/权限）为内部字段，用于控制 Excel 行背景色，**不作为列导出**。

## 优先级标准

| 优先级 | 含义 | 适用场景 |
|--------|------|---------|
| P0 | 冒烟级 | 最核心正向流程，必须通过才能继续测试 |
| P1 | 核心用例 | 主要业务流程，含关键负向 |
| P2 | 增强覆盖 | 次要场景、大多数边界用例 |
| P3 | 边缘用例 | 极端边界、安全注入、罕见异常 |

## 用例类型（test_type）说明

| 类型 | 含义 | 最低比例 |
|------|------|---------|
| 正向 | 合法入参，期望成功响应 | ≥ 40% |
| 负向 | 非法/缺失入参，期望错误响应 | ≥ 30% |
| 边界 | 参数边界值（min/max/null） | ≥ 20% |
| 安全 | SQL注入/XSS/越权等安全场景 | ≥ 10% |

## 验证 SQL 规范

验证 SQL 必须满足：
1. 仅使用 `SELECT`，不包含 DML（禁止 INSERT/UPDATE/DELETE）
2. 包含 `WHERE` 条件，精确定位测试产生的数据
3. 注释说明检查目的：`-- 验证搜索结果包含关键字`
4. 若操作不涉及数据写入（如纯查询接口），填写 `N/A（只读接口）`

**示例：**
```sql
-- 验证地址搜索返回包含关键字的记录
SELECT COUNT(*) FROM lsp_address_suburb
WHERE suburb_name LIKE '%上海%' OR district LIKE '%上海%';
```

| 列宽 | A:12, B:15, C:15, D:25, E:30, F:30, G:20, H:35, I:55, J:55, K:60, L:20, M:10, N:12, O:15, P:12, Q:10, R:8, S:12, T:12, U:15, V:25, W:8, X:10, Y:10 |
