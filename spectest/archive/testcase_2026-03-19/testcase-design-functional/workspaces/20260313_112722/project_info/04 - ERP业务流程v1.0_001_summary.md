# 04 - ERP业务流程v1.0_001 总结

本部分涵盖商品管理与采购入库两大业务模块：

**商品管理**：BG通过0313产品线模块创建采购SKU，经审核后定时下发至WMS/SCP；销售SKU由采购SKU生成Single类型或在0903产品组合SKU中新建组合类型，第三方货主SKU需MTK审核。SY货主通过开放接口创建SKU，Outway货主通过袋鼠系统创建，均需MKT审核后定时同步WMS。商品上架edrop需配置分类、定价、库存分配，通过定时任务同步完成上架。

**采购入库**：BG采购入库流程为：创建EXW/AU采购订单→审核→装柜校对→成本核算→送仓通知→定时推送至SCP/WMS→WMS整单收货关单→库存汇总查验。其他货主（SY/LDX）通过接口创建采购单，Outway分销通过接口创建分销入库单。退货入库分有头件（打印ASN收货清单→RF快捷收货）和无头件（盲收采集）两种方式。配件入库通过0721配件入库单操作，支持自动入库、非自动入库、新增SKU、模板导入四种方式。取消入库在送仓通知前可直接删除，流转后需更新SKU信息发送取消通知并重新核算成本。

**库存管理**：通过0703/0707/0708三个模块从不同维度查看库存；库存分配支持edrop、TW（含预售）、sunyee等平台，通过各自定时任务同步。
