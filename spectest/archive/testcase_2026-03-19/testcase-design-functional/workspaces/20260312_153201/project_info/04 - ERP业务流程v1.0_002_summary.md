# 04 - ERP业务流程v1.0_002 总结

本部分涵盖库存管理（续）与订单出库、配件出库业务模块：

**库存盘点与调整**：盘盈通过WMS预期到货通知新增盘盈单收货关单，消息同步ERP；盘亏通过WMS发运订单新增盘亏出库单完成。盘点支持纸质（PC生成盘点单→打印→录入→生成调整单）和RF（RF获取任务→扫描盘点→PC生成调整单）两种模式，差异需二次确认后生成调整单。库存调整通过新增调整单选类型，编辑目标数量，审核执行后状态关闭，ERP验证数量。

**库存转移**：支持WMS发起（创建转移单→审核→整单转移→ERP确认）和ERP发起（0719库存转移单，支持冻结/解冻/转货主/转质量四种类型）两种方式。

**库存调拨**：非FBA调拨通过0717库存调拨单创建，调出仓WMS发运出库，调入仓WMS预期到货收货，完成后0708仓库库存批次验证增减。FBA/PICKUP调拨通过SCP电商出库执行单处理。

**BG订单出库**：定时拉取neto/edrop平台订单→ERP拦截校验→物流分配→推送SCP→下发WMS→WMS销售订单申报生成label→创建波次→分配拣货→装箱→前置承运商回写→发货→ERP更新已发货。订单被拦截可在0109查看原因。

**代发订单**：SY通过接口/open/v1/createOrder创建（代发归属WH，分销归属sunyee），Outway通过kangaroo系统导入，后续均参考BG订单出库流程。

**配件出库**：通过0102手工订单创建补发类型订单（PARTS-ANONYMOUS），审核后经定时任务推送至SCP/WMS，经波次分配→拣货→出库复核（补充重量体积）→发货完成，库存汇总相应减少。
