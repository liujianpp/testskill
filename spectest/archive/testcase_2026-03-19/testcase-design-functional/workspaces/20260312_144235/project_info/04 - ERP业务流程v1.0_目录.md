# 04 - ERP业务流程v1.0_001
本部分涵盖商品管理与采购入库两大业务模块：BG通过0313产品线模块创建采购SKU，经审核后定时下发至WMS/SCP；销售SKU由采购SKU生成Single类型或在0903产品组合SKU中新建组合类型，第三方货主SKU需MTK审核。SY货主通过开放接口创建SKU，Outway货主通过袋鼠系统创建，均需MKT审核后定时同步WMS。商品上架edrop需配置分类、定价、库存分配，通过定时任务同步完成上架。采购入库流程为：创建EXW/AU采购订单→审核→装柜校对→成本核算→送仓通知→定时推送至SCP/WMS→WMS整单收货关单→库存汇总查验。

# 04 - ERP业务流程v1.0_002
本部分涵盖库存管理（续）与订单出库、配件出库业务模块：库存盘点支持盘盈/盘亏/纸质盘点/RF盘点，差异生成调整单；库存转移支持WMS/ERP发起；库存调拨支持非FBA和FBA/PICKUP两种方式。BG订单出库通过定时拉取各平台订单，经ERP拦截→物流分配→推送SCP/WMS→波次分配→拣货装箱→发货完成全链路。代发订单（SY/Outway）参考BG出库流程。配件出库通过0102手工订单创建补发类型，经波次分配→拣货→出库复核→发货完成。

# 04 - ERP业务流程v1.0_003
本部分涵盖小件出库、自提发货（PICKUP）、取消出库、物流管理、基础信息维护及仓与仓调拨完整流程。小件出库和自提发货均通过WMS波次拣货发货完成；取消出库支持删除和取消订单两种方式；物流模块支持前置承运商回写、电商出库反馈、手工申报单、运费查询；基础信息维护包括仓库、供应商、平台、承运商渠道信息管理；仓与仓调拨完整流程为创建调拨单→审核→调出仓WMS发运→调入仓WMS收货→移库完成。
