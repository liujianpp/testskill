### 问题 2：修改脚本支持新字段名 ✅

**问题描述：**
- `generate_excel.py` 脚本期望的字段名：`name`, `type`, `expected`
- `testcases.json` 使用的字段名：`title`, `test_type`, `expected_result`
- 直接运行会导致数据读取为空

**修复措施：**
1. 在 `generate_excel.py` 中添加 `get_field()` 函数
2. 实现字段映射逻辑：
   ```python
   field_mappings = {
       "title": ["name"],
       "test_type": ["type"],
       "expected_result": ["expected"]
   }
   ```
3. 优先使用直接字段名，再查找映射字段名
4. 修改数据读取部分使用新的 `get_field()` 函数

**修复结果：**
- ✅ 脚本现在可以正确读取新格式的 JSON 文件
- ✅ 同时兼容旧格式和新格式
- ✅ 字段映射逻辑清晰，易于扩展

**文件位置：**
- `spectest/spectest-generate/scripts/generate_excel.py`

**测试验证：**
- 创建 `test_format.py` 验证脚本
- 验证结果：**15个测试用例，所有字段完整** ✅
