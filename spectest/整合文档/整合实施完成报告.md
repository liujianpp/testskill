## 📋 技能清单

### 核心技能（7个）

1. **spectest-new** - 创建变更目录
   - 创建完整的目录结构
   - 生成 proposal.md 模板
   - 关联需求文档

2. **spectest-analysis** - 智能需求分析
   - 提取功能点清单
   - 提取 API 接口清单
   - 生成 requirements-analysis.md

3. **spectest-points** - 生成测试点
   - 支持自动生成模式（调用 testcase 智能）
   - 支持手动编写模式
   - 生成 specs/*.md 测试点文件

4. **spectest-generate** - 生成测试用例
   - from-specs：从测试点生成（简单格式转换）
   - from-api：从 API 文档智能生成
   - from-feature：从功能清单智能生成
   - 输出 25 列 Excel + XMind

5. **spectest-review** - 评审用例
   - 检查覆盖率（正向≥40%、负向≥30%、边界≥20%、安全≥10%）
   - 检查测试步骤可操作性
   - 检查验证 SQL 正确性
   - 检查优先级合理性

6. **spectest-report** - 生成执行报告
   - 汇总执行结果
   - 统计通过率
   - 缺陷摘要
   - 结论与建议

7. **spectest-archive** - 归档变更
   - 移动到 archive/ 目录
   - 添加日期前缀

### 辅助技能（2个）

8. **spectest-convert** - 格式转换
   - 智能映射不同表头格式到标准 25 列
   - 独立使用，不绑定流程

9. **spectest-fix** - 修复用例
   - 根据评审意见自动完善用例
   - 补充缺失的测试场景
   - 修正测试步骤和预期结果
