## 🎯 优化建议

### 优化 1：统一数据格式

**目标：** 确保脚本和数据文件使用统一的字段名

**方案：**
修改 `generate_excel.py` 脚本，添加字段映射逻辑：

```python
# 字段映射
field_mapping = {
    'title': 'name',
    'test_type': 'type',
    'expected_result': 'expected',
    # ... 其他映射
}

def map_field(tc, field):
    """映射字段名"""
    if field in tc:
        return tc[field]
    mapped = field_mapping.get(field)
    if mapped and mapped in tc:
        return tc[mapped]
    return ""
```

**优先级：** P0

### 优化 3：添加快速验证脚本

**目标：** 快速验证生成的文件格式是否正确

**方案：**
创建 `scripts/validate_json.py` 脚本：
```python
import json
import sys

def validate_testcases(json_file):
    """验证 testcases.json 格式"""
    with open(json_file, 'r', encoding='utf-8') as f:
        testcases = json.load(f)

    required_fields = ['project', 'module', 'feature', 'test_item',
                       'title', 'preconditions', 'steps', 'expected_result',
                       'priority', 'case_type', 'test_type']

    errors = []
    for idx, tc in enumerate(testcases):
        for field in required_fields:
            if field not in tc:
                errors.append(f"用例 {idx+1} 缺少字段: {field}")

    return errors
```

**优先级：** P2
