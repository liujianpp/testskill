# operation-manual 使用说明

**网站操作手册生成**技能（Claude Code / Cursor 通用）：根据用户提供的网站 URL 与补充信息，用 **playwright-cli（默认有头模式）** 浏览探索页面、自动截图，输出**带截图引用的 Markdown 操作手册**。适用于操作手册、用户手册、使用指南、系统说明书。

---

## 1. 技能结构

```
operation-manual/
├── SKILL.md                      # 主流程（6 步）
├── browser-cli.md                # playwright-cli 命令参考（内嵌，无需 attach 其他 skill）
├── reference.md                  # 浏览器探索与截图规范
├── examples.md                   # 完整示例
└── templates/manual-template.md  # 操作手册输出模板
```

## 2. 六步工作流

```
Step 1 收集输入 → Step 2 规划探索范围 → Step 3 网站探索与截图 → Step 4 生成大纲(等确认) → Step 5 撰写手册 → Step 6 润色输出
```

### Step 1：收集输入（缺必填项主动询问，收齐后复述确认）

| 字段 | 必填 | 说明 |
|------|------|------|
| 网站 URL | 是 | 起始入口 |
| 产品/系统名称 | 是 | 手册标题 |
| 目标读者 | 否 | 默认「普通业务用户」 |
| 功能范围 | 否 | 未指定则按站点导航自动识别 |
| 补充信息 | 否 | 业务背景、术语、注意事项 |
| 登录方式 | 条件 | 需登录时提供：凭据 / 手动登录 / SSO |
| 输出路径 | 否 | 默认 `{产品名}-操作手册/` |

### Step 2–3：探索与截图（playwright-cli，默认有头）

```bash
playwright-cli --version                    # 可用性检查（不可用则 npx playwright-cli）
playwright-cli open <url> --headed          # ★ 所有 open 必须带 --headed
playwright-cli snapshot                     # 读导航/菜单/功能入口（ref 如 e0/e1）
playwright-cli fill e0 "USER"               # 填表 / click eN 点击
playwright-cli screenshot --filename={产品名}-操作手册/assets/xxx.png
playwright-cli state-save auth.json         # 登录态保存（探索结束删除，不入 git）
playwright-cli close                        # 结束
```

- 首次运行可能触发浏览器下载（约 5–15 分钟，仅首次）
- **截图约定**：存输出目录 `assets/`，命名 `{模块}-{步骤序号}-{简述}.png`，Markdown 用 `![说明](./assets/xxx.png)` 引用；截图后立即记录步骤编号、URL、操作说明
- **需登录页面**：用户给凭据 → headed 打开 → fill → click 登录 → state-save；验证码/SSO → 请用户在可见浏览器窗口完成，回复「已登录」后 snapshot 验证再 state-save。凭据不得写入手册或提交 git；登录失败停止自动化请求协助

### Step 4：生成大纲
按模板出**只含标题与一行要点**的大纲，展示并等用户确认（用户说「直接生成」可跳过）。

### Step 5：撰写手册
- 每步格式：**目的 → 操作 → 截图 → 预期结果**；第二人称「您」、祈使句、一步一截图
- 整合用户补充信息；不含凭据/内部 API/源码；**未探索到的功能标「待补充」，不编造**

### Step 6：润色与输出
- 对说明文字应用 `humanizer-zh` 去 AI 味规则（保留步骤编号与截图引用）
- 交付结构：

```
{产品名}-操作手册/
├── {产品名}-操作手册.md
└── assets/*.png
```

- 报告用户：文件路径、覆盖模块数、截图数、待补充部分；收尾 `close` + 删临时 auth.json

## 3. 质量检查清单

- [ ] 每个功能模块有清晰入口说明
- [ ] 关键步骤均配有截图且路径正确
- [ ] 步骤可独立执行，不依赖隐含知识
- [ ] 无账号密码等敏感信息
- [ ] 术语与用户补充信息一致
- [ ] 未探索到的功能标注「待补充」而非编造

## 4. 工具链边界（工作区约定）

本技能用 **playwright-cli**（snapshot ref e0/e1、有头探索），与 **browser-use CLI**（daemon 常驻、按索引，用于 UI 测试）是两条独立工具链，勿混用（见仓库 CLAUDE.md）。
