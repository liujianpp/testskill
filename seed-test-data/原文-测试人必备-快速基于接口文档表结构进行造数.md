## 引言

造数是测试日常高频工作。很多时候我们只能在页面一步步手动操作来造测试数据，反复点击很耗时间；也有同学直接手写 SQL 插库，字段多、关联多容易乱；还有同学手动拼接口调用，同一场景反复写，重复且容易出错。

那么，有没有更高效、准确的方法来造测试数据？

我的方案：**封装一个 seed-test-data 造数 Skill**，基于接口文档、HAR 包、CURL 语句或者建表 SQL，自动产出 Postman 请求 JSON、SQL 脚本、Python 造数脚本，一键生成测试数据。数据可标识、可追溯、可回滚。

## 一、我的方案：封装 seed-test-data 造数 Skill

先看一下整体的核心能力：

- **1. 支持多源输入**：接口文档（Swagger / OpenAPI / Markdown / 截图）、HAR 抓包文件、CURL 命令、建表 SQL / 表结构说明，四类输入任选其一或组合；
- **2. 输出多格式产物**：Postman Collection JSON（直接导入即可用）、SQL 脚本（新增 + 回滚成对）、Excel 造数表（评审 / 留档）、可执行 Python 造数脚本；
- **3. 智能识别数据链路**：自动识别接口 / 表之间的主从依赖关系，把「公寓 → 房间 → 租客 → 入住」这类串联链路合成一条数据链，ID 自动互传；
- **4. 自动防重与可追溯**：身份证 / 手机号 / 邮箱等唯一约束字段自动加随机段防重复；所有可搜字段统一带 `QA_` 前缀，事后一眼能认出是测试数据，回滚按本批精确业务键删除，不误删。

## 二、Skill 介绍

### 支持的输入源

- **接口文档**：Swagger / OpenAPI、Markdown 接口说明、抓包 / 文档截图、已有 Postman Collection
- **HAR 文件**：浏览器 F12 导出的 .har 抓包
- **CURL**：F12「复制为 cURL」粘贴，或 .sh / .curl / .txt 文件
- **表结构**：DDL 建表语句、`SHOW CREATE`、字段说明表

### 整体逻辑流程

```
解析输入 → 生成「造数清单」（单资源 + 串联链路）→ 用户勾选范围 / 画像 / 数量 / 产物格式
→ 按模板生成文件（Postman / SQL / Excel / Python）→ 自动校验 → 输出交付清单
```

Skill 在生成前会先解析输入、给出清单**让你勾选确认**（范围、画像、数量、格式），不会一上来就追问「你想造什么」，也不会未经确认就乱生成。

## 三、案例实践

### 案例一：基于接口文档造数

**步骤 1：提供接口文档**

把项目的接口文档给到 Skill（Swagger / OpenAPI / Markdown / 截图均可）。本例是一个公寓管理系统的接口文档，包含公寓管理、房间管理、租客管理、入住管理四个模块。

**步骤 2：提出造数诉求**

例如：「帮我造一套完整的测试数据：1 个公寓、1 个房间、1 个租客、完成 1 次入住」。

**步骤 3：自动解析，生成造数清单**

Skill 解析接口文档，识别出模块、接口、必填字段、鉴权方式，以及接口间的依赖关系，生成「造数清单」：

- **单资源**：公寓管理（创建公寓 / 查询公寓 / 删除公寓）、房间管理（…）、租客管理（…）、入住管理（…）
- **串联链路**（识别出依赖时必列）：`创建公寓 → 创建房间 → 创建租客 → 创建入住`（标「推荐」）
- 勾选：范围（单资源 / 串联链路 / 都要）、画像（正常 / +异常 / +边界）、数量、产物格式

**步骤 4：生成产物**

- **Postman Collection + Environment**：文件夹分「造数 / 校验 / 回滚」，请求按依赖排序，上一步创建返回的 id 自动写入环境变量供下一步引用，一键 Run 即可整链造数；
- **Excel 造数表**：数据画像、字段值、来源接口一目了然，可评审可留档；
- **Python 脚本**：`requests` 实现，`seed` / `rollback` 两个子命令，唯一字段每次运行用 `secrets` 现场生成随机值并打印清单。

所有数据带 `QA_YYYYMMDD_` 前缀标识，可搜可查。

### 案例二：基于 HAR 文件造数

没有接口文档？直接把浏览器 F12 导出的 `.har` 文件给 Skill：

- 自动**过滤静态资源与 OPTIONS 请求**，按 `METHOD + path` 去重，先出**摘要**（避免大文件刷屏）；
- 你在摘要里勾选要造数的接口，后续流程与案例一一致。

### 案例三：基于 CURL 造数

临时想快速造几条数据？在 F12 网络面板右键「复制为 cURL」，粘贴给 Skill：

- 自动拆解出 method / path / headers / body，还原成接口清单；
- 适合没有文档、没有抓包的临时快速造数场景。

### 案例四：基于 SQL 表结构造数

**步骤 1：提供建表 SQL**

把相关表的 DDL（或 `SHOW CREATE TABLE`、字段说明表）给 Skill。本例为公寓 / 房间 / 租客 / 入住四张表。

**步骤 2：提出造数诉求**

例如：「基于这些表造 2 套完整数据，1 套正常 1 套异常」。

**步骤 3：解析表结构，生成造数清单勾选**

Skill 解析表、主键、唯一约束、非空、默认值、外键关联，识别出「公寓 → 房间 → 租客 → 入住」的外键链路，生成清单供勾选。

**步骤 4：生成 SQL 产物**

- `{场景}-01_seed.sql`：按外键依赖**正向** INSERT，一条「正常」画像的数据贯穿整条链（ID 互指）；
- `{场景}-02_rollback.sql`：按外键**反向** DELETE，`WHERE` 用**本批精确业务键 / 主键 `IN (...)`**，绝不用 `LIKE 'QA_..._%'` 模糊删（避免误删同日前缀的其他数据）；禁止 `TRUNCATE`、禁止无 WHERE 的 DELETE。

SQL 由**用户自己在测试库手工执行**，Skill 只出文件、不连库、不执行任何 INSERT / DELETE。
