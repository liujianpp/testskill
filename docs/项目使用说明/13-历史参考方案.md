## 4. 新手要不要学它们？

**主线工作不需要。** 现行体系（spectest + testflow + 三支线 + test-automation）已覆盖主要能力。仅当：
- 维护一个仍部署着旧套件的遗留项目（如目录里有 `opentest/changes/`）→ 翻 [16 册](16-技能详解-opentest-用例设计工作流.md)；
- 没有需求文档、想从真实界面直接探索出用例 → 翻 [14 册](14-技能详解-playwright-cli-testcase-探索式用例生成.md)；
- 界面含 Canvas/Shadow DOM/图形验证码等难定位元素、又要代码化进 CI → 翻 [15 册](15-技能详解-playwright-midscene-混合UI自动化.md)。
