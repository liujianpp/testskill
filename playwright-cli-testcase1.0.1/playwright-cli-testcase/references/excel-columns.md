# Excel 字段与填写规范

## 表结构

- Sheet 名：`测试用例`
- 首行冻结
- 步骤、预期在单元格内用换行（`\n`）分隔

## 列定义

| JSON 字段 | Excel 表头 | 填写规范 |
|-----------|------------|----------|
| `case_id` | 用例编号 | `TC_001` 起，模块内连续或全局连续均可 |
| `module` | 模块 | 功能子系统名，如「登录」「订单列表」 |
| `title` | 用例标题 | 一句话说明测什么 + 条件，勿写「测试xxx」空标题 |
| `priority` | 优先级 | 仅 `P0` / `P1` / `P2`（冒烟 / 核心 / 次要） |
| `precondition` | 前置条件 | 账号、数据、环境、入口页等；无则写「无」 |
| `steps` | 测试步骤 | 编号步骤，每步一个动作 |
| `expected` | 预期结果 | 与步骤对应或按结果点编号，可观察、可判定 |
| `method` | 设计方法 | 如「等价类」「边界值+场景法」 |
| `page` | 页面 | 页面路径、标题或路由，如 `/login`、`订单详情` |
| `notes` | 备注 | 风险、依赖、数据准备、探索备注；可空 |

## JSON 顶层

| 字段 | 说明 |
|------|------|
| `title` | 需求名或页面标题（也用于 XMind 中心主题、默认文件名简称） |
| `assumptions` | 可选；生成时的假设说明（含「未提供需求文档」等） |
| `cases` | 用例数组，元素字段同上表 |

## 优先级建议

- **P0**：主流程冒烟，失败则阻塞提测/上线
- **P1**：核心分支、校验、权限、关键异常等高价值路径
- **P2**：次要入口、文案、低概率组合、体验优化类
