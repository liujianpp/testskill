# Web 测试用例设计方法与维度

## 经典设计方法（何时用 + Web 示例）

| 方法 | 何时用 | Web 示例 |
|------|--------|----------|
| 等价类 | 输入可分区且区内行为一致 | 邮箱合法/非法格式；状态筛选各选项 |
| 边界值 | 有明确上下限、长度、数量 | 密码最短/最长；分页首页末页；上传大小临界 |
| 判定表 | 多条件组合决定结果 | 优惠券 + 会员 + 活动日是否可叠加 |
| 场景法 | 主流程与分支用户路径 | 登录→浏览→下单→支付→结果页 |
| 状态迁移 | 对象有明确状态机 | 订单：待付→已付→发货→完成 / 取消 |
| 正交 | 多因子组合需降维覆盖 | 浏览器 × 分辨率 × 角色（需求明确时） |
| 错误推测 | 经验驱动的异常与脏数据 | 连点提交、浏览器后退、重复打开 Tab、XSS 字符 |

## Web 专项关注点

| 专项 | 关注要点 |
|------|----------|
| 表单校验 | 必填、格式、长度、前后空格、重复提交、客户端与服务端一致 |
| 列表/CRUD | 增删改查、空列表、搜索无结果、分页排序、批量操作 |
| 导航与路由 | 菜单入口、深链、刷新、前进后退、404、权限跳转 |
| 空态/加载/错误 | Loading、骨架屏、超时、接口失败提示、重试 |
| 弹窗/抽屉 | 打开关闭、遮罩点击、Esc、未保存离开提示 |
| 权限角色 | 未登录、无权限菜单隐藏/禁用、越权访问提示 |
| 会话 | 登录过期、多 Tab、登出后返回受保护页 |
| 兼容/性能 | 仅在需求明确时加强：分辨率、主流浏览器、首屏与列表卡顿 |

## 维度检查表（按页面勾选）

### A 通用

- [ ] 功能正确性（主流程 + 分支）
- [ ] UI/交互（点击区域、文案、遮挡、返回栈）
- [ ] 表单校验与边界
- [ ] 空态 / 加载 / 错误提示
- [ ] 刷新、后退、深链
- [ ] 异常与中断（断网提示若可见、重复提交）

### B 有鉴权时加强

- [ ] 登录成功/失败/锁定
- [ ] 有验证码时：正确、错误、过期、刷新（探索时不逐条实操破坏性重试；写入用例覆盖）
- [ ] 未登录访问受保护页
- [ ] 角色权限差异
- [ ] 会话过期与重新登录

### C 有需求文档时加强

- [ ] 需求规则与界面实现一致性
- [ ] 需求中的异常与边界是否可在 UI 触发
- [ ] 需求有而界面无 / 界面有而需求无（记入计划差异）

## 输出质量红线

- 每条用例必须有可执行步骤与可判定预期
- 至少覆盖：正常路径、关键异常、关键边界（按模块体量裁剪）
- 禁止：「验证 xxx 功能正常」「随便点点看」等空描述
- `method` 字段写清所用方法（可组合，如「边界值+错误推测」）
