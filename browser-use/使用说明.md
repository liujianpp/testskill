# browser-use 使用说明

`browser-use` CLI 的封装参考技能（Claude Code / Cursor 通用）：后台 **daemon 常驻**保持浏览器跨命令存活（单次调用约 50ms 延迟），通过 **`state` 返回的元素索引**驱动交互。它是通用浏览器自动化能力（导航、表单、截图、取数），**不是测试专用技能**；在本工作区中作为 [browser-use-case-runner](../browser-use-case-runner/使用说明.md) 的 **CLI 命令契约源**（case-runner 只引用此处文档化的子命令，不得臆造如 `browser-use ocr` 等未文档化命令）。

> 本技能目录仅 3 个文件：SKILL.md（命令总表）+ references/cdp-python.md（原生 CDP 进阶）+ references/multi-session.md（多会话）。无脚本、无模板。

---

## 1. 核心工作流

```
browser-use open <url>      # 打开页面（默认无头）
browser-use state           # ★ 拿到 URL/标题/可点击元素及其索引
browser-use click 5         # 用 state 里的索引交互
browser-use input 3 "text"  # 点击元素→清空→输入
browser-use state / screenshot   # 验证
（浏览器保持打开，跨命令复用）
```

**铁律**：先 `state` 拿索引再交互；命令失败先 `browser-use close` 清会话再重试。

## 2. 浏览器模式

```bash
browser-use open <url>                      # 默认：无头 Chromium（零配置）
browser-use --headed open <url>             # 可见窗口（调试用）
browser-use connect                         # 连接用户已开的 Chrome（保留登录态/cookies）
browser-use cloud connect                   # 云端浏览器（零配置，需 API key）
browser-use --profile "Default" open <url>  # 用指定 Chrome 配置启动受管 Chromium
```

`connect` / `cloud connect` 后，后续命令自动走该浏览器，无需额外参数。

### connect 失败时的两个选项（须让用户选，不替用户拍板）
1. **真实 Chrome**：开 `chrome://inspect/#remote-debugging` 或带 `--remote-debugging-port=9222` 重启 Chrome，再重试 `connect`。
2. **受管 Chromium + Chrome 配置**：`browser-use profile list` 列出配置 → 用户选一个 → `browser-use --profile "ProfileName" open <url>`（独立 Chromium 实例，带 cookies/登录态/扩展）。

## 3. 命令速查

| 类别 | 命令 |
|------|------|
| 导航/Tab | `open` `back` `scroll down\|up [--amount N]` `tab list/new/switch/close` |
| 状态 | `state`（元素索引来源）、`screenshot [path.png] [--full]`（无路径输出 base64） |
| 交互（用索引） | `click <index>`、`click <x> <y>`、`type`、`input <index> "text"`、`input <index> ""`（仅清空）、`keys "Enter"`、`select`、`upload`、`hover`、`dblclick`、`rightclick` |
| 数据提取 | `eval "js"`、`get title/html/text/value/attributes/bbox` |
| 等待 | `wait selector "css" [--state ...]`、`wait text "text"` |
| Cookies | `cookies get/set/clear/export/import` |
| 会话 | `close`、`sessions`、`close --all` |
| 配置 | `config list/get/set/unset`（存 `~/.browser-use/config.json`）、`doctor`（诊断）、`setup` |

CLI 别名：`bu` / `browser` / `browseruse` 均可用。

## 4. 命令链式

`&&` 链式安全高效（daemon 保持状态）：

```bash
browser-use open https://example.com && browser-use state
browser-use input 5 "user@example.com" && browser-use input 6 "password" && browser-use click 7
```

**不需要中间输出时链式；需要先解析 `state` 发现索引时分开跑。**

## 5. 多会话（`--session NAME`）

每个命名会话独立：自己的 daemon、socket（`~/.browser-use/{name}.sock`）、浏览器实例、tab 归属锁。适用：云浏览器抓取 + 本地 Chrome 带登录任务并行、隔离测试浏览器、调试有头 + 后台无头并行。

```bash
browser-use --session work open <url>   # 进 'work' 会话
browser-use --session work state
browser-use state                       # ★ 忘带 --session 会落到 default——最常见错误
export BROWSER_USE_SESSION=work         # 环境变量方式，免每条加 flag
browser-use sessions                    # 列出各会话与 PHASE 状态
```

## 6. 云端与隧道

```bash
browser-use cloud connect               # 开通并连接云浏览器（持久 profile，打印 live URL）
browser-use cloud login <api-key>       # 或环境变量 BROWSER_USE_API_KEY
browser-use cloud v2 GET /browsers      # REST 直通（v2/v3）
browser-use tunnel <port>               # Cloudflare 隧道暴露本地服务 → https://xxx.trycloudflare.com
browser-use tunnel list / stop --all
```

注意：`browser-use close` 会**同时断开并停掉**云浏览器。无 API key 时可走 `cloud signup` 三步自注册（challenge → verify → claim）。

## 7. 进阶：Python + 原生 CDP

CLI 不够用时（激活 tab 给用户看、拦截网络、设备仿真、直接操作 Chrome target）：

```bash
browser-use python "cdp = browser._run(browser._session.get_or_create_cdp_session())"
browser-use python "browser._run(cdp.cdp_client.send.Target.activateTarget(params={'targetId': targets[1].target_id}))"
```

- 每次 `python` 调用**一条语句**，变量跨调用持久（`cdp` 设一次处处可用）
- `browser`（预注入同步封装）、`browser._run(coroutine)`（60s 超时）、`browser._session`（原始 BrowserSession）
- 全部 CDP 域可用：`cdp.cdp_client.send.<Domain>.<method>()`
- 常用配方（tab 激活 / Runtime.evaluate / 移动端仿真 / CDP 取 cookies）见 [references/cdp-python.md](references/cdp-python.md)

## 8. Tips 与故障排查

| 症状 | 处理 |
|------|------|
| 浏览器起不来 | `browser-use close` → `browser-use --headed open <url>` |
| 找不到元素 | `browser-use scroll down` → `browser-use state` |
| 会话异常 | `browser-use close`（或 `close --all`）后重试 |
| 环境诊断 | `browser-use doctor`（含安装、配置、api_key 检查） |

收尾：`browser-use close`；有隧道再 `browser-use tunnel stop --all`。

## 9. 在本工作区的角色

- **依赖方向**：browser-use-case-runner 的 CLI 行为契约以本技能为准（`state`/`input`/`click`/`screenshot`）；case-runner 的会话策略（fresh-per-case 的 `close --all` + `headed open`）直接复用本 CLI。
- **工具链边界**（见仓库 CLAUDE.md）：UI 测试用 browser-use CLI（daemon 常驻、按索引）；操作手册生成用 playwright-cli（snapshot ref e0/e1）。两套勿混用。
