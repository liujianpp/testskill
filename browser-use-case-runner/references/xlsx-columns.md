# xlsx 表格式用例表结构

## 推荐表头（中文，首行）

与仓库内 `test-data/用户登录-测试用例.xlsx` 等文件对齐时，使用下列列名（顺序可调整，脚本按**表头名**匹配）：

| 列名 | 导出 JSON 字段 | 说明 |
|------|----------------|------|
| 用例编号 | `id` | 唯一标识，如 `TC-LOGIN-001` |
| 用例名称 | `name` | 可与编号分列；若合并到一列，脚本可将「编号+名称」填入 `id`/`name` |
| 功能模块 | `module` | 可选 |
| 优先级 | `priority` | P0/P1… |
| 前置条件 | `preconditions` | |
| 测试步骤 | `steps` | 多步换行可保留在单元格内 |
| 测试数据 | `data` | |
| 预期结果 | `expected` | |

若表头为「用例名称」单列且含编号，可将该列同时映射到 `name`，`id` 从首列「用例编号」读取。

## 与登录页字段的对应提示（示例）

执行时 Agent 将「测试步骤/测试数据」映射到页面控件，常见对应关系：

- **用户名** → 占位「用户名」的输入框
- **密码** → 「密码」输入框；眼睛图标 → 显隐切换
- **验证码** → 「验证码」输入 + 右侧图片 + 刷新图标；若 `state` 读不出图中字符，按主 skill：**`browser-use screenshot` 落盘 → 带视觉的 Agent 识别 → 仍失败则人工输入**。
- **登录** → 主按钮「登录」

具体索引以每次 `browser-use state` 为准。
